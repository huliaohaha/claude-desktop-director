# 0.2.0-rc1 验证记录

日期：2026-10-31。此版是候选版本，以下验证层次分开报告。

## L1：离线结构、状态与分发

- 本机 Python 3.12：54 项单元测试通过，包含全文读回声明、目标与时间关系、unknown 状态约束、验收证据类型、非有限 JSON、异常文件输入及诊断转义。
- 包检查确认版本元数据、相对链接、26 个行为场景、20 个触发用例与示例正文哈希。当前宿主的技能格式检查通过；兼容要求放在受支持的 `metadata.requirements` 中。
- GitHub Actions 首次检查提交 `b510d31`：Python 3.10、3.12、3.13 通过，见 [该次运行](https://github.com/huliaohaha/claude-desktop-director/actions/runs/41272187594)。后续发行提交的状态见 [检查工作流](https://github.com/huliaohaha/claude-desktop-director/actions/workflows/validate.yml)。
- 在临时技能目录验证安装与文件一致性；已有目标时返回非零状态，并保留原文件。匿名克隆与候选标签安装在发布后另行复核。

状态校验器仅验证记录的内部声明，不读取证据引用，不验证屏幕、记录真假或用户授权，不拦截真实点击。它没有实现发送幂等、跨进程锁、记录写入器或后台运行。

## L2：文字场景排练

两名独立智能体分别读取 v0.1.0 和初次候选指令，为相同的 25 个场景输出动作计划，并给出 20 个技能选择判断。评估者拿不到这些场景的预期答案；另一个审阅者按冻结的断言独立评分。

| 初次单次排练 | v0.1.0 | 初次候选 |
|---|---|---|
| 文字断言满足 | 70 / 75 | 72 / 75 |
| 文字断言全部满足的场景 | 21 / 25 | 22 / 25 |
| 选择判断与给定标签一致 | 20 / 20 | 20 / 20 |

这不是桌面任务成功率。每个版本用同一智能体上下文批量处理场景，未进行逐例会话隔离或多次重复，也没有实际或模拟桌面 API 的调用轨迹。选择判断是在已有技能上下文中进行，不是宿主真实自动发现测试；精确模型构建、采样参数和用量未取得。评分包含措辞覆盖判断，不能推出真实操作一定安全或不安全。

初次排练暴露的缺口及处理：

- 候选的 GitHub 调研任务未明确索取仓库链接：补齐链接与具体复用判断要求。
- 两版预算交接都没有具体恢复动作：补齐重新绑定会话、观察工具状态、核对产物和剩余验收的交接要求。
- 隐私场景的一条断言要求检查已经放弃使用的仓库路径，过于严格：后续素材改为检查实际写入位置；初次评分保持原样，不重新计算分数。
- 旧版消息没有 Message-ID 的兼容问题由另一轮审查发现：增加无歧义原文与上下文核对分支，不补造历史 ID；新 JSON 记录从下一条新协议消息开始。

随后用新初始化的智能体定向排练了修订后的两个场景及旧消息恢复场景。输出包含调研链接要求、具体恢复动作、旧消息确认及新证据续问。这些单次定向结果与初次对照分开保存，没有混入上表，也不作为完整新版回归通过的声明。
