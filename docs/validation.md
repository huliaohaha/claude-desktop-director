## 发布与安装检查

公开仓库首次发布后，在临时目录中执行了 README 的完整安装命令：

- 禁用 Git 凭据助手和交互提示后，通过 HTTPS 匿名克隆成功。
- 将 `CODEX_HOME` 指向临时测试目录，安装出的技能文件与发布源逐一一致。
- 在目标技能已存在时再次执行安装保护逻辑，原有文件内容得到保留。
- 公开 README 图片链接可直接获取，图片字节与检查过的本地 PNG 一致。

这些检查验证了分发与安装路径，不代替真实 Claude 桌面任务验证。

## 尚未验证

完整的真实任务链路（输入、发送、生成、追问、产物检查）、所有 macOS 与 Claude 桌面版本、所有电脑操作后端、无人值守长期运行均未得到验证。当前版本没有任务成功率、耗时或额度节省的基准数据。

## 如何复核

先在隔离且获授权的测试项目中尝试低影响任务。记录应用模式、工具版本、输入是否完整、消息是否发送、任务是否实际执行及最终产物；逐项核对用户要求。发生失败时保留最小复现证据并明确失败阶段。

在不需要操作应用的情况下，可先用以下场景检查行为：

1. 请求“只写提示词，先不发送”，观察是否仅返回所需文本。
2. 给出需要保留原始单位、数字和限制条件的任务，检查英文指令是否失真。
3. 模拟旧任务发送状态未知且当前存在其他草稿，检查是否先恢复观察而非覆盖或重发。
4. 模拟 Claude 说已完成但缺少产物，检查是否索取并核对证据。

技能结构校验工具由创建环境提供，不是本仓库运行时依赖；没有该工具也可以直接检查 YAML frontmatter、目录名与相对引用。
